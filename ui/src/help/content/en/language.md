# Language

Micelio has two distinct languages, chosen by different people.

## The interface language {#ui}

It is **personal**: switch it with **IT / EN** at the bottom of the sidebar. It applies to every screen, the guide, the daemon's error messages, the date and number format and, in the desktop app, the tray menu and notifications. It is remembered across restarts (in the browser or the app); the first time the system language is used.

## The language of memories {#team-language}

It belongs to the **team** and is chosen by the admin on the Team page: distilled memories are born in this language, whatever the language of the session or document. It exists because keyword search and dreaming work better on memories written in the same language (meaning-based search works across languages anyway).

## What stays in the original language {#data}

What was **written** by the team or generated as data: titles and texts of memories, reasons of the flags on Roots, dream summaries, reasons in the private log. The command line and the answers to agents (MCP) are in Italian as well.
